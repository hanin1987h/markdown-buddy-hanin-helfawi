**Student:** Hanin Helfawi
**Course:** BDA400 - Data Science Tools and Techniques
**Assignment:** 5 - Development Phase

## Project Overview
This project implements nine technical analysis indicators in base R without external libraries.

## Indicators
1. Simple Moving Average (SMA)
2. Exponential Moving Average (EMA)
3. Moving Average Convergence Divergence (MACD)
4. Standard Deviation
5. Linear Regression
6. Relative Strength Index (RSI)
7. Stochastic RSI
8. Crossover
9. Crossunder

## How to Run
Open R or RStudio and use source("filename.R") to load each indicator function. Run the test script after uploading the implementation files.
